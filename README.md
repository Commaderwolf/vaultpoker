# ♠ VaultPoker

P2P Texas Hold'em in your browser. No server. No account. Free forever on GitHub Pages.

## How to Deploy

1. Create a GitHub repo called `vaultpoker` (Public)
2. Upload `index.html` and `manifest.json`
3. Settings → Pages → Branch: main → / (root) → Save
4. Your link: `https://YOUR_USERNAME.github.io/vaultpoker`

## How to Play

1. **Player 1** opens the link → clicks **Create Room** → shares the code
2. **Player 2** opens the same link → pastes code → clicks **Sit Down**
3. Game starts automatically — heads-up Texas Hold'em!

## Rules
- Heads-up (2 players)
- $5 small blind / $10 big blind
- Dealer alternates each hand
- Standard hand rankings — Royal Flush down to High Card
- Full betting: Fold, Check, Call, Raise

## Features
- Real shuffled deck dealt client-side
- Full hand evaluation at showdown
- Works on iPhone, Android, and PC
- Installable as a home screen app
- No server — WebRTC P2P direct connection
- 100% free via GitHub Pages
